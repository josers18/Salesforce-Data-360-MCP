## [0.1.0] - 2025-10-26

### Added
- Core `MCPOpenAIBridge` class
- Async context management for MCP connections
- OpenAI function calling integration
- Interactive chat CLI (`interactive_chat.py`)
- Streamlit daemon-based UI (`streamlit_app_daemon.py`)
- MCP daemon for background processing (`mcp_daemon.py`)
- Docker and Docker Compose configuration
- Complete documentation suite
- Example configurations
- Test suite
- GitHub Actions CI/CD workflows

### Features
- Natural language querying of Salesforce Data Cloud
- Automatic tool discovery from MCP servers
- Conversation history management
- Multiple deployment options (CLI, Web UI, Docker)
- Debug and logging capabilities
- Error handling and recovery

### Documentation
